# 衣境 · Gallery Reader

适合手机、平板和桌面浏览器的 E-Hentai / ExHentai 图集阅读器。收藏优先同步到源站，失败时保存在本机；阅读进度与设置保存在当前浏览器，已加载的列表和图片可从本机恢复。

## 本地运行

需要 Node.js 22+。

```sh
npm install
npm run dev
# http://localhost:3000
npm test
npm run build
node scripts/serve.mjs dist
```

开发服务器和 Vercel 部署共用同一组 API。`dist/` 是应用界面，实时接口需要 Node.js 服务或 Vercel Functions，不能只部署到纯静态文件服务器。

## 使用

- “发现”复用当前来源的 Popular 热门页，默认保留源站热度顺序，热门最多 50 本，滚动到底部后自动接上普通列表并去重；“全部图集”浏览源站最新列表。首页热门支持全局分类，搜索词仍进入正常源站搜索，也支持粘贴完整图集链接。
- 源站热门依据最近一分钟访问热度，从过去 24 小时发布的图集中排列，属于全站热门而非个性化推荐（[源站说明](https://ehwiki.org/wiki/Galleries#Popular)）。热门页为空、当前分类没有热门或热门临时不可用时自动切换最新图集；凭证失效仍提示重新验证。热门页不自动轮询，点击刷新获取当前结果；返回和刷新保留续接位置、分页游标与去重结果。
- 在“阅读偏好 → 全局筛选分类”中多选 E-Hentai 的 10 个顶级分类，点击“应用分类”后对发现、搜索、收藏和足迹生效；默认选择全部分类。
- 列表卡片不展开图集标签以减少高度；详情页保留完整标签。正常网格在封面左下角显示已有元数据中的有效评分，紧凑列表模式则在信息行显示，缺失或未评分时不显示，不额外请求评分；评分人数和评论仍在打开“评分与评论”后按需读取。点击图集详情或列表筛选面板中的快捷标签，以该标签向源站精确搜索相关图集，保留全局分类设置。
- 热门榜接上常规图集时，热门图集与常规图集分组排列，中间显示分割线和“以下为常规图集”；热门为空或暂时不可用时保留对应占位说明，再显示分割线与常规图集。其他排行榜在当前筛选下为空时，也显示占位说明和分割线。各组内保留所选排序，返回时恢复分组。
- 列表接近底部时沿源站游标自动滚动加载，保留分类、搜索条件与已加载结果；加载失败时显示重试。首次加载、滚动续载和刷新按钮均显示旋转动画，请求期间禁用刷新以避免重复请求。连续空页自动预填有边界，继续上滑才会继续查找，避免无操作时持续请求。
- 搜索页保存最近搜索，空白搜索页显示快捷入口，可一键重搜、逐条删除或清空。每个来源及搜索范围（全部、收藏、足迹）最多保留 20 条，重复搜索置顶；提交搜索或离开已使用的搜索页时保存，避免把每个输入中间状态都记入历史。记录仅在本机保存，清除或切换凭证时清除私有来源和账号收藏的搜索记录。
- 各主列表通过右上角常驻搜索按钮进入独立的二级搜索页，标签、高级搜索和以图搜图也使用该页面。搜索页返回恢复来源列表的榜单、排序、滚动和分页；从图集返回保留搜索词、筛选与结果。空白搜索页不请求源站列表。
- 仅本地收藏保留图集 ID、token 与已加载元数据；历史记录保留图集 ID 和 token。首次打开或手动刷新列表时获取源站元数据。
- 足迹卡片显示最近访问时间，支持删除单条记录和清空全部足迹；删除同时移除该阅读进度，收藏与图片缓存保留。再次打开已有足迹图集的缩略图详情页时更新最近访问时间，返回足迹后按最近访问排序并保留原阅读页码。
- 阅读方式在照片预览与上下连续阅读之间切换，保留当前页码与进度。设置页只保留分类、主题、缓存、记录和内容源凭证；旧版逐页阅读的默认方式与翻页方向设置已移除，使用说明折叠收起。
- 图集详情默认显示照片缩略图网格；点击照片进入横向预览，支持顺滑左右滑动、底部胶片条跳转，再点击进入全屏。全屏时轻点退出到带底部缩略图的预览；预览和全屏均可下滑直接返回图集网格。
- 图册缩略图提前加载上下约 2 屏，底部胶片条提前准备左右约 1 屏；仍按需读取源站缩略图分页并复用已加载的批次，不下载整本原图。
- 连续阅读时点击某张图片进入全屏，支持相同的缩放和拖动手势；单击或下滑返回连续阅读。未换图时恢复原来的滚动偏移，换图后返回到全屏当前图片。此入口与缩略图网格的全屏返回方式分别保存。
- 照片支持双击放大/复原、双指缩放（1–4 倍）、放大后单指拖动；按图片实际显示边界限制拖动。放大时不触发翻页或下滑退出，复原后恢复左右翻页、单击切换全屏和下滑返回图册；单击稍作等待以区分双击。
- 照片预览中可切换上下连续阅读，切换时保持当前照片；各模式均按当前页移动预载窗口，提前加载前后各 5 张图片，后台最多 3 张并发。预载复用本地图片缓存，跳页会替换等待队列，退出后停止预载。
- 详情和阅读器采用单页导航，返回时保留搜索、分类、排序、布局、已加载结果与滚动位置。浏览器返回/前进可逐层导航，发现、收藏、足迹和全部图集分别保留各自的列表状态。
- 当前浏览器标签页通过 sessionStorage 保存浏览快照，刷新后恢复列表；进行中的列表请求继续执行，刷新时恢复未完成的加载。需要最新结果时点击列表右上角的刷新按钮。
- 已加载的图片通过浏览器 Cache API 保存，再次查看优先读取本地；每个来源会话最多缓存 200 张。设置页可查看数量和浏览器估算的缓存占用并清除缓存。浏览器只提供全站存储统计时，明确显示“本站存储占用”（包含其他本地数据）；不支持统计时显示不可用，不把跨域图片的不可读响应误记为 0 字节，也不额外下载图片来统计。PWA 更新保留图片缓存，未缓存图片仍需要网络。
- ExHentai 图片缓存和浏览快照按来源/会话隔离，清除凭证时删除私有缓存；清除浏览器数据会移除收藏与进度。

## 源站功能

- 发现页切换实时热门、昨日榜、月榜、年榜、总榜和关注页；各榜单保留源站顺序、翻页游标和返回位置。日、月、年、总榜共用 E-Hentai 的公开榜单入口，ExHentai 没有独立的 toplist.php；选择 ExHentai 时仍使用 ExHentai 获取元数据和阅读，公开榜单请求不携带账号凭证。源站榜单不原生按分类过滤，阅读器先从榜单 HTML 排除已知的不选分类，再对加载结果应用完整筛选，减少无用元数据请求。
- 高级搜索面板支持作者、上传者、语言、排除标签、最低评分、页数范围、有种子及已下架图集；所有条件与搜索词、分页共同保存。
- 以图搜图可选择相似搜索、仅封面搜索（上传最大 3 MB），或在浏览器计算 SHA-1 进行精确匹配。图片只转发给当前源站，不写入服务器文件或浏览器持久缓存。
- 关注/屏蔽、高亮颜色和 -99 至 99 的标签权重保存到源站 My Tags；读取的当前标签集也用于本机列表过滤。首页快捷标签优先显示关注标签，其余按当前图集中的出现频率排列。
- 收藏页合并当前账号的源站收藏与仅本地收藏并去重，列表卡片不提供收藏按钮，新收藏统一从详情页底部入口操作；当前账号已确认的源站收藏在右下角页数旁显示小型只读实心爱心标记，未知状态不显示爱心，避免把未知状态当作未收藏。进入详情时按需读取源站收藏状态，同账号已确认的状态复用以减少请求。详情页只保留底部一个收藏入口，已收藏时点击可调整分组、备注或取消收藏。每次收藏优先提交源站，提交期间显示转圈、禁用重复操作，并保留提交前的选中状态，确认结果后才更新，已收藏的爱心显示为实心；未登录或提交失败时保存在本地、显示“仅本地”并提示原因；仅本地条目显示标记和“同步到源站”按钮。源站收藏按收藏时间请求，避免按图集发布时间把新收藏排到后面；刚收藏的图集即使尚未出现在源站收藏第一页，也保留已确认结果，避免分页刷新将它清掉。源站收藏状态读取图集页真实标记，不把收藏表单的默认分组当成已经收藏；提交后再次回读确认。同步成功后删除本地收藏记录及元数据，源站收藏仅保留当前会话浏览缓存，以源站数据为准。切换账号不显示旧账号源站收藏，仅本地收藏跨账号保留。收藏设置仍支持源站十个分组与备注，默认操作先读取已有分组/备注以避免覆盖。
- 图集详情可按需打开评分与评论、标签投票、种子和压缩包下载面板。评论采用紧凑间距与无边框的点赞、点踩图标。评分、评论、投票、收藏和标签偏好只在用户提交时写入源站；源站 API key 仅在服务器读取使用，不返回浏览器。
- 压缩包先显示源站费用和尺寸，用户点击生成后才提交；下载链接和种子由浏览器直连源站/下载服务器，Vercel 不转发文件。检查下载状态由用户触发，不后台轮询。
- 关注、源站收藏与账号操作需要设置页中的有效账号凭证。普通 E-Hentai 浏览保持匿名，只有明确的账号功能请求会将账号 Cookie 发给 E-Hentai 或其 API；ExHentai 请求仍限于 ExHentai 域名。清除凭证会清除账号列表快照、标签偏好和私有图片缓存。
- 全站按钮与导航使用同一套 SVG 图标；底部导航以主题色背景、顶边和加粗文字显示当前页面，触摸点击不出现键盘焦点框；移动端表单控件统一至少 16px，避免 iOS 聚焦输入框自动放大，同时保留手动缩放。主列表顶栏固定显示，首页直接展示榜单切换和图集，去掉重复的推荐横幅与介绍。刷新保留在列表标题右侧；分类、排序、布局、快捷标签、高级搜索、以图搜图和标签偏好统一收进“筛选”面板，默认不占用内容空间；窄屏下列表标题与筛选入口保持同一行。

## 导出图片下载清单

在图集详情点击“下载 → 导出下载清单”，选择页码范围并生成 JSON，可保存到“文件”或使用系统分享菜单交给通用下载器。每次最多 200 张；更大的图集可以分段导出。生成有进度和停止按钮，失败项可以单独重试，也可保存已经成功的部分。

生成时复用已读取的缩略图分页，并分批解析源站图片页；每批最多 8 张、同时解析 2 张，不下载图片字节，不生成源站压缩包。ExHentai 只在解析源站页面时使用浏览器已验证的凭证，导出文件不包含 Cookie 或账号信息。清单包含临时图片直链，应妥善保存。

H@H 直链可能约 15 分钟失效，应生成后立即使用。过期后点击“重新生成”，在下载器选择“继续已有任务”；JSON 中每张图片的稳定 `id` 按来源、图集 ID 和页码生成，刷新地址、分段导出或改变后缀都不会改变它，因此已完成图片无需重新下载。未完成单张文件不保证跨 URL 字节续传。

JSON 格式为 `{version:1,name,items:[{id,url,filename}]}`，可以供任何兼容工具使用；通用下载器无需适配本网站。原图由下载器直连 CDN，不经过 Vercel。解析仍受源站访问额度和频率限制；额度不足时停止，不将占位图导出为成功结果。

## ExHentai 凭证

在“阅读偏好 → 内容源与凭证”中填写 `ipb_member_id`、`ipb_pass_hash`、`ipb_session_id`，可选填 `igneous`。点击“验证并保存”后，只有源站访问验证通过才可切换到 ExHentai。失效的 `igneous` 会尝试使用基础凭证重新取得。

凭证通过同源 HTTPS 提交，保存在本机浏览器的 `Secure`、`HttpOnly`、`SameSite=Strict` 持久 Cookie 中，有效期一年，检查会话时自动续期。关闭浏览器后仍可恢复；现有会话会自动升级，保留私有图片缓存。凭证设置位于阅读偏好最底部；打开设置时以密码输入框回填已保存凭证，可直接修改并更新，关闭设置后清空表单。只有设置页的同源请求会读取凭证，接口响应不缓存。凭证不写入 localStorage、sessionStorage、Git 或 URL，也不在服务器数据库中保存。可以随时点击“清除凭证”；清除浏览器数据或源站凭证失效后需要重新验证。ExHentai 与 E-Hentai 使用相同的 10 个顶级分类和筛选编号。

## 实时接口

| 路径 | 用途 |
| --- | --- |
| `GET /api/galleries?q=关键词&next=游标&f_cats=排除分类掩码&feed=popular` | 读取热门或搜索列表，返回图集 ID、token 和下一页游标（热门无分页） |
| `GET /api/pages?gid=ID&token=TOKEN&p=缩略图分页` | 按需读取源站小图或拼图裁剪信息，避免下载整本原图 |
| `POST /api/image-links?source=来源` | 分批解析指定图集的图片页直链，供浏览器生成下载清单；不转发图片字节 |
| `GET /api/image?gid=ID&token=TOKEN&page=页码` | 解析图片页，以 302 跳转到原始图片 |
| `GET/POST/DELETE /api/ex-session` | 检查、验证或清除 ExHentai 会话 |
| `GET/POST /api/source` | 按需读取评论、账号标签、收藏分组、下载选项，提交账号操作或以图搜图 |
| `POST /api/metadata` | 取得需要认证的 ExHentai 元数据 |
| `GET /api/thumbnail` | 取得需要认证的小尺寸 ExHentai 封面 |

阅读和下载清单使用源站图片页 `#img` 的展示图片地址，应用不二次压缩，但源站可能根据设置缩放或重采样，因此不保证是上传原文件。

E-Hentai 元数据直接从浏览器请求 `https://e-hentai.org/api.php`，封面和原图也直连源站/CDN。ExHentai 需要凭证的元数据、搜索及小尺寸封面经过 Vercel；原图解析后仍以 302 让浏览器直连 CDN，Vercel 不转发原图。接口加 `source=exhentai` 时必须持有已验证会话。

图片在当前页前后各 5 张的窗口内预载，范围外保留占位；图片地址跳转在浏览器私有缓存中保留 5 分钟，减少重复解析。搜索 API 响应不缓存，列表浏览快照保留在当前标签页；Service Worker 仅缓存应用界面和图片，凭证及元数据 API 不进入缓存。源站返回错误、限流或不可用时，界面显示错误并提供重试。

## 部署

`vercel.json` 指定 `npm run build` 和 `dist/`。根目录 `api/` 中的接口作为 Node.js Vercel Functions 部署，无数据库或环境变量要求。构建只打包应用界面并更新 PWA 缓存版本。

GitHub 仓库：[`polish1020/ehentai-reader`](https://github.com/polish1020/ehentai-reader)。已有 Vercel 项目为 `changsheng/ehentai-reader`，Production Branch 为 `main`。将变更合并到 `main` 后由 Git 集成自动构建。

生产域名：`ehentai.polishwb1020.com`。
